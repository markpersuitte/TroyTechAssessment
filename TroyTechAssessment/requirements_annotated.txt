ANNOTATED REQUIREMENTS
======================

Create a full-stack web application for a property management company that accepts rental applications for its apartments. A property manager maintains properties and their units. An applicant applies for a unit and, if approved, is issued a lease. There are only two roles in this system: an applicant and a property manager. There are certain actions that an applicant and a property manager can perform; ensure the permissions in the controllers and the UI reflect this.

Status: COMPLETE.
Handled in:
- TroyTechAssessment/Program.cs
- TroyTechAssessment/Data/ApplicationUser.cs
- TroyTechAssessment/Pages/Index.cshtml.cs
- TroyTechAssessment/Pages/Apply/Apply.cshtml.cs
- TroyTechAssessment/Controllers/ReviewController.cs
- TroyTechAssessment/Controllers/PropertiesController.cs
- TroyTechAssessment/Controllers/UnitsController.cs

The application uses ASP.NET Core Identity, Applicant/Manager roles, role-scoped UI, server-side ownership checks, manager property assignments, application review, and lease creation.

a. The applicant can create, fill out, submit, and withdraw applications for available units, and correct and resubmit an application that was returned.

Status: COMPLETE.
Handled in:
- TroyTechAssessment/Pages/Apply/Apply.cshtml.cs
- TroyTechAssessment/Pages/Apply/_ApplicationForm.cshtml
- TroyTechAssessment/Pages/Apply/_ResidenceHistorySection.cshtml
- TroyTechAssessment/Pages/Apply/_ApplicationSummary.cshtml

Draft and Returned applications are editable. Continue, Save Draft, Submit, and Withdraw actions are server-validated. Submitted applications can be returned and then corrected/resubmitted.

b. The property manager maintains properties and units and reviews submitted applications. An approved application issues a twelve-month lease for the unit.

Status: COMPLETE.
Handled in:
- TroyTechAssessment/Pages/Index.cshtml.cs
- TroyTechAssessment/Controllers/PropertiesController.cs
- TroyTechAssessment/Controllers/UnitsController.cs
- TroyTechAssessment/Controllers/ReviewController.cs
- TroyTechAssessment/Pages/Apply/Apply.cshtml.cs
- TroyTechAssessment/Data/Lease.cs

Managers maintain properties and units through modal actions. Review approval creates a twelve-month inclusive lease and records the status transition.
